# $10K by December

A personal savings tracker that installs to a phone home screen as a web app.

Open the site in Safari on iPhone, tap **Share**, then **Add to Home Screen**.
On Android, open it in Chrome and choose **Install app** or **Add to Home screen**.

All entries are stored only on the device that entered them (browser storage).
Nothing is sent to a server, and the site holds no personal data.
Use **Settings → Export JSON backup** to keep a copy.
